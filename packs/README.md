# Language packs

One folder per language, named after its language code:

```
packs/<code>/pack.json     the pack: Turbo EA's "Share (community pack)" export
packs/<code>/MAINTAINERS   who reviews changes to it (written by automation / the owner)
```

To add a language, use **Add file → Create new file** here and type
`<code>/pack.json` as the name. See [CONTRIBUTING.md](../CONTRIBUTING.md).
